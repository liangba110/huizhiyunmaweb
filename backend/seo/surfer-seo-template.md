# Surfer SEO 白帽优化模板（百度适配版）

## 内容评分标准（100分制）

### 1. 字数（30分）
- ≥2000字：30分
- 1500-1999字：20分
- 1000-1499字：10分
- <1000字：0分

### 2. 标题结构（20分）
- H1：1个（必须包含主关键词）
- H2：3-5个（覆盖主要子话题）
- H3：2-4个（补充细节）
- 完整结构：20分
- 部分结构：10分
- 无结构：0分

### 3. 内链（20分）
- ≥3个内链：20分
- 1-2个内链：10分
- 0个内链：0分

### 4. 图片优化（15分）
- ≥2张图片，均有alt标签：15分
- 1张图片：5分
- 无图片：0分

### 5. 段落结构（15分）
- ≥5个段落：15分
- 3-4个段落：10分
- <3个段落：0分

## 关键词密度（1-3%）
- 主关键词在标题、首段、末段出现
- LSI关键词自然分布
- 避免堆砌

## 内容结构模板

```
H1: 主关键词 + 吸引点

引言（100-150字）
- 痛点/问题引入
- 文章价值说明

H2: 核心概念/背景
- 定义解释
- 行业现状
- 数据支撑

H2: 主要内容/方案
H3: 方案一
- 详细说明
- 案例/数据
- 优缺点

H3: 方案二
- 详细说明
- 案例/数据
- 优缺点

H3: 方案三
- 详细说明
- 案例/数据
- 优缺点

H2: 实施步骤/操作指南
- 步骤1：详细说明
- 步骤2：详细说明
- 步骤3：详细说明

H2: 常见问题/注意事项
- 问题1：解答
- 问题2：解答
- 问题3：解答

H2: 总结与建议
- 核心要点回顾
- 行动建议
- 内链引导

内链位置：
1. 首段：链接到相关服务页
2. 中间：链接到案例页
3. 末尾：链接到相关文章
```

## 百度优化要点

1. **标题**：包含主关键词，长度20-35字
2. **描述**：120-160字，包含关键词
3. **H1**：每页仅1个，包含主关键词
4. **内容**：原创、有价值、解决用户问题
5. **内链**：相关性强，锚文本自然
6. **更新频率**：定期更新，保持活跃

## 避免的SEO风险

1. ❌ 关键词堆砌
2. ❌ 隐藏文本/链接
3. ❌ 采集/伪原创
4. ❌ 重复内容
5. ❌ 低质量外链
6. ❌ 过度优化锚文本
