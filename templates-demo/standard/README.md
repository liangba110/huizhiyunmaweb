## 🚀 部署方式
1. 将全部文件上传到您的服务器任意目录
2. 配置Web服务器（Nginx/Apache）指向 index.html
3. （可选）配置域名和SSL证书

### Nginx配置示例
```nginx
server {
    listen 80;
    server_name yourdomain.com;
    root /path/to/template;
    index index.html;
}
```
